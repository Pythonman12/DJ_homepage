1. 프로젝트 배경 및 서비스 목적

OVERVIEW & OBJECTIVES
추진 배경 및 문제의식 BACKGROUND

대진전자통신고 학생들은 정규 교과뿐만 아니라 알고리즘 프로그래밍, 회로 기판 실습, 전자 캐드, 디자인 포트폴리오, 국가기술자격증 실기 등 전공 영역에서 지속적인 질문과 실습 에러에 직면합니다.

  • 교내 위계나 신원 노출 부담 없이 소통할 수 있는 안전한 익명 공간의 부재
  • 정형화된 카테고리에 얽매이지 않고 자유롭게 질문하고 답변을 채택할 수 있는 지식 공유 체계 필요
  • 나이스(NEIS) 오픈 API와 결합된 모바일 최적화 학교 일정 및 식단 접근성 필요
핵심 추진 목표 CORE GOALS

단순 정보를 나열하는 웹사이트가 아닌, 학생들의 학업과 전공 성장을 일상 속에서 실질적으로 돕는 맞춤형 플랫폼을 구축합니다.

  • 대진 전용 포털: 나이스 오픈 API 기반 중식 급식 식단표 및 4개 학과·1~10반 시간표 실시간 제공
  • 100% 무조건 익명성: 프로필 칩부터 게시글, 댓글, 답변까지 일체의 실명 노출을 원천 배제
  • 능동적 동적 달력: 12월 ↔ 1월 연도 롤오버 및 Date 객체 기반 실시간 그리드 연산
  • 특성화고 진로 로드맵: 산학일체형 도제학교, 산업기능요원(병특), 선취업 후진학 안내

4. 능동적 동적 달력 연산 엔진 명세

CALENDAR ENGINE SPECIFICATION
연도 자동 롤오버 (Year Rollover) ROLLOVER

과거의 고정된 월 탐색 한계를 벗어나 연도를 넘나드는 학사일정 및 개인 일정 관리가 가능하도록 구현되었습니다.

  • 12월 → 1월 전진: 12월에서 > 버튼 클릭 시 연도가 1년 증가하고 1월로 전환 (예: 2026.12 → 2027.01)
  • 1월 → 12월 후진: 1월에서 < 버튼 클릭 시 연도가 1년 감소하고 12월로 전환 (예: 2027.01 → 2026.12)
  • 오늘 복귀: '오늘' 버튼 클릭 시 당월(2026년 10월)로 즉각 리셋
Date 객체 기반 시작 요일 및 일수 자동 연산 GRID CALCULATION

하드코딩된 더미 일자(27, 28, 29, 30...)를 제거하고 표준 브라우저 Date API로 정확한 날짜 배치를 보장합니다.

  • new Date(year, month - 1, 1).getDay(): 해당 월 1일의 시작 요일(0:일 ~ 6:토) 동적 산출
  • new Date(year, month, 0).getDate(): 해당 월의 총 일수(28/29/30/31일) 동적 산출
  • prevMonthTailDays: 이전 달의 실제 마지막 날짜들을 역순 계산하여 첫 주 공백에 정확히 채움
  • nextMonthHeadDays: 7일 그리드 배수를 맞추기 위해 다음 달 1일부터 필요한 일수를 동적 렌더링
